# AlkExpress24

Online-Shop für Getränke-Expresslieferung zu Events in Graz. Statische Seite für GitHub Pages.

## Anpassen

Alles Wichtige steht oben im `<script>` von `index.html`:

- `CONFIG.whatsapp` – deine WhatsApp-Nummer (z. B. `43664xxxxxxx`). Leer = Bestellung per E-Mail.
- `CONFIG.email`, `minOrder`, `fee`
- `CONFIG.impressum` – vor dem Livegang ausfüllen (Pflicht)
- `CATALOG` – Produkte und Preise (`age: 16` für Bier/Wein/Sekt, `18` für Spirituosen)

## Vor dem Start

- Gewerbe (Handelsgewerbe) anmelden, Impressum/AGB/Widerrufsbelehrung rechtlich prüfen lassen
- Bei jeder Übergabe Ausweis kontrollieren – die Altersprüfung auf der Website ersetzt das nicht
